This is the official repository for the Academic Enrichment course at the Medical College of Wisconsin (Essentials of Biomedical Informatics). This is the support material for a 4-week course. The main objective is to develop skill to build and analyze a real patient cohort using the same data standard (OMOP) that powers national research networks like All of Us, N3C, and PCORnet. No prior programming experience is assumed. Every concept is introduced step by step. Every exercise includes a fully worked example before asking you to try it yourself. Every tool you'll use is free and open-source. Whatever you learn from this course, you can keep using long after the course ends.

Each module is self-paced and asynchronous. Plan for roughly 3–4 hours per week to complete each module. Each week has its own Module Guide covering that week's concepts, software setup, and exercise instructions. 

Each week has a self-check quiz to be completed before completing the deliverable for the week. A grading rubric is available for each week.

Each week also has one or more companion code files (R and/or Python, and SQL from Week 2 onward). Every code file follows the same two-part structure: Part 1 (a fully worked example) and Part 2 (a short exercise to complete yourself, which is the graded deliverable).
